# PhysChem for Humanity

Open, bilingual physical chemistry knowledge and computational tools for human progress.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Deploy the `dist` directory to Cloudflare Pages. With Git integration use build command `npm run build` and output directory `dist`.

## Content

- `/en/` — English edition
- `/ru/` — Russian edition
- `.mdx` pages can import React tools and scientific visualizations.

## Scientific scope

Educational calculations should state assumptions and units. Results must not be treated as experimental or medical advice without domain validation.
