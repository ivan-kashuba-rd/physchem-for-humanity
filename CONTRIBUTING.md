# Contributing

Thank you for improving PhysChem for Humanity.

1. Open an issue describing the scientific or technical change.
2. Cite primary literature and include DOI links where possible.
3. State assumptions, standard states, units and validity limits for calculations.
4. Add or update both English and Russian content when feasible.
5. Run `npm run build` before opening a pull request.

Scientific contributions should distinguish peer-reviewed evidence, preprints,
educational approximations and original interpretation.
